## 🌿 About the Project

This repository hosts the live web portfolio for **Wiinox**, highlighting a blend of ancestral Nisga'a cultural heritage with modern digital and physical mediums. The platform showcases nontraditional formline, beadwork, digital illustration, and multimedia projects aimed at contemporary expression and cultural revitalization.

---

## 🎨 Featured Mediums & Work

- **Nontraditional Formline:** Contemporary interpretations of traditional Northwest Coast shapes, structures, and symmetry.
- **Beadwork & Wearable Art:** Precision geometric designs and craft wire techniques on contemporary apparel.
- **Multimedia & Audio:** Digital illustration, storytelling, and indie podcast production.
- **Language & Revitalization:** Digital resources and visual materials supporting the Nisga'a language.

---

## 🛠️ Built With

- **HTML5:** Semantic, accessible markup.
- **CSS3:** Responsive layout using Flexbox, CSS Grid, and custom variables.
- **Vanilla JavaScript:** Interactive gallery components, mobile navigation, and UI states.
- **GitHub Pages:** Static site hosting and deployment.
